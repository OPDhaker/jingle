## 3. Hear it

### Four tags, built in.

No audio files needed. jingle comes with four sounds and starts with sensible defaults.

| Sound | What it is | Plays on |
|---|---|---|
| **chime** | Two-note rising bell | every commit |
| **fanfare** | Quick rising brass arpeggio | every successful push |
| **harmony** | Two voices resolving to a chord | merge commits (opt-in) |
| **boom** | Snare hit into an 808 drop | yours to assign |

*[A play button on each row. Export the WAVs with `jingle play <event> --sound <name> --wait`: jingle renders each one to `~/.local/share/jingle/sounds/builtin/<name>.wav`. They're generated by jingle's own code and MIT-licensed, so you can host them on the site.]*

## 4. Install

### Two commands. Every repo.

**Homebrew**

```sh
brew install OPDhaker/tap/jingle
jingle install --yes
```

**Install script** (puts the binary in `~/.local/bin`, no sudo, checks the sha256)

```sh
curl -fsSL https://raw.githubusercontent.com/OPDhaker/jingle/main/install.sh | sh
jingle install --yes
```

**Go** (1.25+)

```sh
go install github.com/OPDhaker/jingle/cmd/jingle@latest
jingle install --yes
```

Then check it works:

```sh
jingle play commit
jingle doctor
```

## 5. How it works

### Commit. Push. Hear it.

1. **You commit.** chime plays the moment the commit lands.
2. **You push.** fanfare plays once the push actually goes through. Rejected pushes and "Everything up-to-date" stay silent.
3. **You merge** (if you turn it on). harmony plays for real merge commits. Fast-forwards and squash merges stay quiet.

`jingle install` points git's global hooks at jingle once. There's nothing to set up in each repo, nothing to commit, and no background process.

## 6. Safe to install

### It stays out of git's way.

- **Your hooks keep running.** Every repo's own hooks still run, with the same arguments, input, and exit codes. Lint and test hooks work exactly as before.
- **Never slows you down.** The sound plays in the background and git never waits for it. It adds a few tens of milliseconds per commit.
- **Quiet when it should be.** Rebases, cherry-picks, and reverts don't set off a sound per commit. A burst of commits plays once.
- **Leaves no trace.** `jingle uninstall` puts your git config back byte for byte, exactly as it was before.

```sh
jingle uninstall --yes --purge
```

## 7. Bring your own tag

### Your sound, your signature.

Got a producer tag? Use it. jingle keeps its own copy, so you can move or delete the original.

```sh
jingle config set commit.sounds ~/Music/my-tag.mp3
jingle config set push.sounds builtin:boom
jingle config add commit.sounds ~/Music/tag2.wav    # several sounds: one plays at random
jingle config set volume 60
```

Plays mp3, wav, aiff, m4a, ogg, and flac.

```
/plugin install jingle --marketplace OPDhaker/jingle
```

- **`jingle skill`** prints the setup guide for any agent, matched to your installed version.
- **`jingle schema`** describes every command, setting, and error code as JSON.
- Every command takes `--json`, never prompts, and is safe to run twice.

## 9. FAQ

**Does it work in every repo?**
Yes, with one exception. Repos that manage their own hooks with husky (or that set their own `core.hooksPath`) override jingle, so it stays silent there. `jingle doctor`, run inside the repo, tells you when this happens.

**How do I mute it?**
`jingle config set enabled false`. The hooks stay installed; run `jingle config set enabled true` to turn the sound back on. To mute only pushes: `jingle config set push.enabled false`.

**Will it play in CI or on a server?**
Only if the machine has an audio player. Headless machines usually don't, so it stays silent.

**What does it need?**
macOS (uses `afplay`, built in) or Linux (`pw-play`, `paplay`, `aplay`, or `ffplay`), and git. Detecting a successful push needs git 2.28 or newer; on older git, the push sound plays when the push starts.

**Windows?**
Planned, not supported yet.

**What if I delete the binary without uninstalling?**
git keeps working. The hooks skip the sound and still run your own hooks. Run `jingle uninstall` first for a clean removal.
